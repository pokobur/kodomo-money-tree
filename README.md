# こどもマネーツリー (Kodomo Money Tree) 🌳💰

親子で楽しくお金の仕組み・金利・お小遣い管理・クエスト（お手伝い）を学べる金融教育Webアプリケーションです。

---

## 🌟 主な機能

- **クエスト機能**: 親がミッションを作成し、子どもが報告、親が承認することで報酬コインを獲得。
- **ちょきんばこ & つかえるおかね**: 報酬を「つかえるお金」と「ちょきん」に分散・管理。
- **週利・月利（金利ルール）**: 預けた貯金に利息がつくことで、投資・貯蓄の複利効果を体感。個別付与サイクル（曜日・日付指定）にも対応。
- **収支に連動した貯金グラフ**: 過去の取引履歴（報酬、金利、出金、振替）から実残高を逆算し、7日間（日別）・4週間（週別）の推移を美しく可視化。
- **ほしいものリスト & 出金申請**: 目標を立てて貯金し、出金申請を親子で確認。
- **オフライン・オンライン両対応**: Supabaseクラウド同期 + LocalStorage完全フォールバック。

## 🚀 デプロイ方法

### 方法1: GitHub Pages（推奨・自動ビルド）
本リポジトリには GitHub Actions による自動デプロイワークフロー (`.github/workflows/deploy.yml`) が含まれています。

1. GitHub リポジトリの **Settings** > **Pages** を開きます。
2. **Build and deployment** の **Source** を **`GitHub Actions`** に設定します。
3. `main` ブランチにプッシュされると自動的にビルドされ、Webアプリとして公開されます。

### 方法2: Vercel / Netlify / Cloudflare Pages
1. Vercel や Cloudflare Pages に本リポジトリを連携します。
2. ビルドコマンド: `npm run build`
3. 出力ディレクトリ: `dist`
4. 環境変数 (`.env`):
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
